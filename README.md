# QianuHub 闲鱼助手

一个面向个人使用的闲鱼管理后台。项目使用 Go 提供服务端，使用 React 构建 Web 管理界面。

## 当前功能

- 账号管理：扫码登录、账号启停、状态查看和账号信息维护。
- 在线聊天：按账号查看会话与消息，并发送文本、图片和闲鱼表情。
- 卡密库存：维护文本、图片、链接等电子资料，并按库存发送。
- 商品列表：同步商品、查看商品状态、编辑商品，以及发布单规格商品。
- 订单管理：同步订单、查看订单状态、手动处理发货和补发资料。
- 自动化规则：付款后自动发货、确认发货、付款后重新上架原商品，以及超时未评价求评价。
- 通知设置：配置通知渠道和通知规则。
- 仪表盘：查看账号、订单、商品和营收等本地统计。
- 系统设置：配置管理员账号、日志和运行相关设置。

项目当前不包含以下功能：AI 客服、拍下未付款自动改价、评价后发送赠品、批量铺货、多规格商品和发货模板。

## 使用说明

### 便携版

从 [Releases](https://github.com/ZAQ0405/QianuHub-Xianyu-Helper/releases) 下载便携版，解压后双击 `QianuHub.exe`。
便携版已包含服务端和浏览器运行文件，不需要另外安装 Go、Node.js 或浏览器。

首次打开 `http://127.0.0.1:59188` 时设置管理员密码。项目不预置管理员密码。

### 从源码运行

环境要求：Go、Node.js/npm，以及 Playwright 所需的浏览器运行环境。

```bash
npm --prefix frontend ci
npm --prefix frontend run build
go run ./cmd/server -db data/xianyu_data.db -addr 127.0.0.1:59188
```

然后访问 `http://127.0.0.1:59188`。首次初始化时设置管理员密码。

Windows 本地开发也可以运行仓库根目录的 `一键启动.bat` 或 `start-local.ps1`。

## 自动发货流程

1. 在“卡密库存”创建电子资料库存。
2. 在“商品列表”同步或选择闲鱼商品。
3. 在“自动化规则”创建“付款后自动发货”规则并关联商品与库存。
4. 按需配置确认发货文案和“付款成功并发送资料后，自动确认发货并重新上架原商品”。
5. 买家付款后，系统发送资料，提交确认发货，并在启用重新上架时恢复原商品，不创建新商品。

实际执行结果以闲鱼返回和订单状态为准。遇到平台验证、接口拒绝或状态不确定时，后台会保留任务记录供核对。

## 注意事项

这是非官方个人工具，不代表闲鱼或阿里巴巴，也未获得其授权。项目使用闲鱼网页端接口，使用前请自行确认平台规则、账号授权和法律风险。

不要把账号密码、Cookie、二维码、数据库、日志或密钥提交到公开仓库。运行数据默认保存在本地 `data` 和 `logs` 目录。
